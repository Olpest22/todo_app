# Список дел (Flutter)

Мобильное приложение для управления задачами в стиле Material Design 3.

## Возможности

- **Добавление** задачи с текстом и важностью (кнопка «Новая задача»).
- **Отметка выполнения** чекбоксом: выполненная задача зачёркивается.
- **Редактирование** текста, важности и статуса (нажатие на задачу или меню «⋮ → Изменить»).
- **Удаление** свайпом влево или через меню, с возможностью отмены в SnackBar.
- **Сортировка** (иконка в AppBar): сначала новые, сначала старые, по важности, по алфавиту.
- **Фильтрация** по статусу: все, активные, выполненные (со счётчиками).
- **Сохранение данных** на устройстве через `shared_preferences` (JSON).
- Светлая и тёмная тема, следуют настройкам системы.

## Структура проекта

```
lib/
├── main.dart                     // точка входа, тема приложения
├── models/task.dart              // модель задачи и важности
├── services/task_storage.dart    // сохранение и загрузка задач
├── controllers/task_controller.dart // состояние и бизнес-логика
├── screens/home_screen.dart      // главный экран
├── utils/date_format.dart        // форматирование даты
└── widgets/
    ├── task_tile.dart            // карточка задачи
    ├── task_editor_sheet.dart    // форма добавления/редактирования
    ├── priority_badge.dart       // значок важности
    └── empty_state.dart          // экран пустого списка
test/
└── task_controller_test.dart     // юнит-тесты логики
```

## Запуск

Требуется Flutter 3.10 или новее.

```bash
cd todo_app
flutter create .      # создаст папки платформ (android, ios и т.д.), код в lib/ не изменится
flutter pub get
flutter run
```

Запуск тестов:

```bash
flutter test
```
